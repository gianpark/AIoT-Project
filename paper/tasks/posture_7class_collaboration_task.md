# 7개 자세 클래스 재정의 및 후속 작업 지시서

-   작업 목적: 교수님 지시에 따라 자세 분류 기준을 기존 9개 클래스에서
    7개 클래스로 재정의한다.
-   작업 방식: 본 문서는 공동작업자를 위한 작업 명세서이며, 이번
    단계에서 코드는 직접 수정하지 않는다. 담당 공동작업자가 데이터 라벨
    변환 및 실험 코드를 수정한다.
-   주의: 기존 9-class 실험 결과와 파일은 보존하고, 7-class 실험은 별도
    결과물로 관리한다.

## 1. 변경 목표

6가지 주요 자세는 각각 구분하고, 나머지 자세는 하나의 `bad_posture`
클래스로 통합한다. 최종 출력 클래스는 총 7개다.

## 2. 제안 라벨 매핑

  최종 클래스   최종 라벨                         원본 라벨
  ------------- --------------------------------- -------------------------------
  0             `normal` (정자세)                 `normal`
  1             `turtle_neck` (거북목)            `neck_hard`, `neck_light`
  2             `forward` (몸을 앞으로 기울임)    `forward`
  3             `lean_back` (뒤로 기댐)           `back_hard`, `back_light`
  4             `left_lean` (왼쪽으로 기움)       `left_lean_neck`
  5             `right_lean` (오른쪽으로 기움)    `right_lean_neck`
  6             `bad_posture` (그 외 나쁜 자세)   `back_neck`, `chin`, `slouch`

**중요:** 위 매핑은 현재 파악된 원본 라벨 이름을 바탕으로 한 작업안이다.
코드 수정 전에 실제 CSV 전체의 라벨 목록과 기존 라벨 정의/촬영
프로토콜을 대조해야 한다. 의미가 불명확하거나 목록에 없는 라벨은 임의로
매핑하지 말고 담당자에게 확인한다. 특히 좌우 기울임 라벨이 실제 데이터에
존재하는지 확인한다.

## 3. 담당 공동작업자 작업 항목

1.  프로젝트 전체 CSV에서 원본 라벨의 고유값과 클래스별 샘플 수를
    집계한다.
2.  위 매핑안과 실제 라벨 정의를 대조하고, 불일치 또는 미확인 라벨을
    보고한다.
3.  매핑이 확정되면 원본 라벨을 보존한 채 7-class 라벨 컬럼을 생성한다.
4.  변환 후 클래스별 샘플 수를 출력하고, 매핑되지 않은 라벨이 0개인지
    검증한다.
5.  학습/평가 코드의 클래스 목록, 라벨 인코딩, 혼동행렬 표시 이름 등
    7-class 기준으로 수정한다.
6.  기존과 동일한 참가자 단위 LOPO 평가를 적용해 RF, XGBoost, LightGBM을
    비교한다.
7.  각 fold의 Accuracy, Macro-F1, 클래스별 Precision/Recall/F1 및
    혼동행렬을 저장한다.
8.  기존 9-class 결과와 새 7-class 결과가 혼동되지 않도록 파일명과
    보고서에 클래스 수를 명시한다.

## 4. 검증 및 주의사항

-   참가자 단위 LOPO 분할 원칙은 유지한다.
-   결측치 처리 및 학습 데이터 기준 전처리 원칙이 기존 실험과 동일한지
    기록한다.
-   `bad_posture`에 여러 자세가 합쳐지므로 클래스 내부의 자세 다양성이
    커질 수 있다. 결과 해석 시 이를 한계로 명시한다.
-   7-class 결과는 9-class 결과와 직접적인 성능 우열 비교 자료로
    사용하지 않는다. 분류 문제가 달라졌기 때문이다.
-   좌우 기울임 데이터가 없거나 부족하면 임의로 데이터를 만들어 넣지
    말고 데이터 수집 필요 여부를 보고한다.
-   이번 작업에서는 모델 튜닝을 먼저 진행하지 않는다. 우선 라벨 기준과
    기본 알고리즘 비교를 재현 가능하게 정리한다.

-   확정된 7-class 라벨 매핑표
-   라벨 변환 코드 및 변환 결과 검증 로그
-   7-class RF/XGBoost/LightGBM 비교 결과표
-   fold별 결과 CSV와 혼동행렬
