# 개인 자세 보정 기능 구현 보고서

## 1. 작업 목적

사용자마다 다른 기본적인 목·상체 위치 차이로 인해 자세 판정 결과가 달라질 수 있으므로, 프로그램 실행 중 사용자가 평소의 정상 앉은 자세를 직접 지정하고 해당 기준에 맞춰 목 내밈 특징값을 보정하는 세션 단위 기능을 추가했다.

이번 작업은 기존 자세 판정 임계값을 변경하지 않고, `judge()`에 전달하기 직전 `neck_forward_offset_m`만 보정하는 방식이다.

## 2. 변경 파일

| 파일 | 변경 사항 |
|---|---|
| `src/logic/personal_calibration.py` | 개인 기준값 수집, 중앙값 계산, 보정값 적용, 상태 문자열 제공 |
| `src/pose/movenet_keypoints.py` | 보정기 생성, 유효 샘플 수집, `judge()` 입력 연결, `c` 키 처리 및 화면 상태 표시 |

## 3. 동작 방식

1. 실행 시 `--personal-calibration` 옵션을 지정하면 개인 보정기를 생성한다. 이 옵션은 `--judge`와 함께 사용해야 한다.
2. 사용자가 화면에서 평소의 정상 앉은 자세를 유지한 뒤 `c` 키를 누르면 수집을 시작한다.
3. 코와 양쪽 어깨의 키포인트 신뢰도가 각각 0.50 이상이고, 깊이 특징값이 존재하며 `near_invalid`가 아닌 경우에만 샘플 후보로 사용한다.
4. 샘플 간격은 0.15초 이상으로 제한하고, 유효한 `neck_forward_offset_m` 값 150개를 수집한다.
5. 수집값의 중앙값을 개인 기준값으로 계산한다. 보정 목표값은 0.143m이며 오프셋은 `개인 기준값 - 0.143m`로 계산한다.
6. 판정 시에는 복사한 특징값 딕셔너리의 `neck_forward_offset_m`만 `현재값 - 오프셋`으로 변경하여 기존 `judge()`에 전달한다.

## 4. 기존 기능과의 관계

- 기존 `decision.py`의 자세 판정 임계값은 수정하지 않았다.
- 기존 `r` 키의 카메라 사용자 재인식 동작은 유지하고, 개인 보정에는 `c` 키를 사용한다.
- 보정은 프로그램 실행 중 메모리에서만 유지되며 파일에 영구 저장하지 않는다. 프로그램을 다시 실행하면 새로 보정해야 한다.
- 개인 보정 기능을 활성화하지 않으면 기존 판정 입력 경로를 그대로 사용한다.

## 5. 실행 방법

RealSense 카메라 및 기존 실행 환경이 준비된 상태에서 기존 실행 명령에 다음 옵션을 추가한다.

```powershell
# 기존 실행 명령에 두 옵션을 포함
python -m src.pose.movenet_keypoints --judge --personal-calibration
```

실제 프로젝트의 실행 방식에 따라 모델 경로, 카메라 옵션 등 기존 인자는 함께 유지해야 한다. 실행 후 정상 앉은 자세를 유지하고 `c` 키를 눌러 보정을 시작한다.

## 6. 검증 현황

| 검증 항목 | 결과 |
|---|---|
| `PersonalPostureCalibrator` import | 통과 |
| 초기 상태 문자열 출력 | 통과 — `Personal calibration: press 'c' to calibrate` |
| 두 수정 Python 파일 문법 검사(`py_compile`) | 통과 |
| 실제 카메라 샘플 수집 | 미실시 — 카메라 미연결 |
| 실시간 보정 후 자세 판정 검증 | 미실시 — 카메라 미연결 |

따라서 현재 확인된 것은 모듈 import와 Python 문법 수준이다. 실제 환경에서 150개 샘플이 안정적으로 수집되는지, 정상 자세 오경고가 감소하는지, 앞으로 숙이기 및 뒤로 기대기 등 비정상 자세 검출 성능이 유지되는지는 D455 연결 후 별도로 검증해야 한다.

## 7. 해석상 주의사항

보정 목표값 0.143m는 기존 오프라인 개인별 보정 분석에서 사용한 기준값이다. 기존 실시간 판정 코드의 `NECK_OUT_REF_M = 0.15m`와는 목적이 다른 값이므로 서로 동일한 임계값으로 취급하지 않는다.

또한 `neck_forward_offset_m`은 목 내밈뿐 아니라 기존 판정 로직의 다른 분기에도 영향을 줄 수 있다. 따라서 보정 후 정상 자세뿐 아니라 뒤로 기대기 및 목을 앞으로 내미는 자세도 함께 확인해야 한다.

## 8. 다음 작업

1. D455 연결 후 `--judge --personal-calibration`으로 실행한다.
2. 정상 앉은 자세에서 `c` 키를 눌러 150개 샘플을 수집한다.
3. 보정 완료 전후의 정상 자세 판정 결과를 비교한다.
4. 앞으로 숙이기, 뒤로 기대기, 좌우 기울임 자세를 각각 시험해 비정상 자세 검출이 유지되는지 확인한다.
5. 검증 결과를 별도 실험 로그로 기록하고 필요하면 보정 샘플 수와 유효성 조건을 조정한다.
