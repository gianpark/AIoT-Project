## 1. 실험 개요

-   **데이터:** `data/side_env2`
-   **참가자:** p01, p02
-   **전체 프레임:** 10,107
-   **보정 기준:** `REF_NF = 0.143 m`
-   **보정 이동량:** p01 `+0.044 m`, p02 `+0.063 m`
-   **보정 대상 특징:** `neck_forward_offset_m`
-   **실험 방식:** 참가자별 정상 자세 로그의 `neck_forward_offset_m`
    중앙값을 환경 1의 정상 기준값인 `0.143 m`에 맞추도록 모든 프레임의
    값을 동일한 양만큼 이동했다. 다른 특징과 판정 임계값은 변경하지
    않았다.

## 3. 정상 자세 판정률 변화

  참가자     보정 전 정상 판정률(%)   보정 후 정상 판정률(%)   변화(%p)
  -------- ------------------------ ------------------------ ----------

정상 자세에서 `slouch_back`으로 잘못 판정된 비율은 p01이 96%에서 0%,

## 4. 결과 분류 및 해석

### 4.1 개선된 항목

-   `forward`: p01 0% → 82%, p02 0% → 66%
-   `neck_hard`: p01 0% → 99%, p02 84% → 97%
-   `neck_light`: p01 0% → 88%
-   `left_lean_neck`: p01 0% → 39%
-   `right_lean_neck`: p01 30% → 44%, p02 0% → 10%
-   `slouch`: p02 0% → 59%

기대 kind 검출률이 개선된 사례가 확인됐다. 특히 `neck_hard` p01과
`neck_light` p01, `forward` 두 참가자에서 변화 폭이 컸다.

### 4.2 하락한 항목

-   `back_light` p01: 100% → 87%(-13%p)
-   `chin` p02: 10% → 8%(-2%p)

보정 후 일부 자세에서 기대 kind 검출률이 낮아졌다. 따라서 보정이 모든
자세의 검출 성능을 일괄적으로 향상시킨 것은 아니다.

### 4.3 변화가 없거나 여전히 검출되지 않은 항목

-   `chin` p01: 0% → 0%
-   `left_lean_neck` p02: 0% → 0%
-   `neck_light` p02: 0% → 0%
-   `slouch` p01: 0% → 0%
-   `back_hard` 두 참가자: 모두 100% 유지
-   `back_light` p02: 100% 유지

참가자에 따라 동일한 자세의 결과가 다르게 나타났다. 특히 `neck_light`,
`left_lean_neck`, `slouch`에서 참가자 간 차이가 확인된다.

### 4.4 `back_neck` 참고 결과

`back_neck`은 결과 파일에서 기대 kind가 지정되지 않아 기대 kind 검출률을
계산하지 않았다. 정상 판정률은 p01이 2% → 79%, p02가 1% → 79%로
기록됐다. 이 수치만으로 해당 자세의 올바른 검출이 개선됐다고 결론 내릴
수는 없다.

## 5. 종합 결론

환경 2에서 참가자별 정상 자세 기준으로 `neck_forward_offset_m`을 보정한
결과, 두 참가자의 정상 자세 판정률은 각각 4%에서 100%, 2%에서 100%로
높아졌다. 또한 `forward`, `neck_hard` 등 일부 이상 자세에서 기대 kind
검출률이 개선됐다.

반면 `back_light` p01과 `chin` p02에서는 검출률이 하락했고, `chin` p01,
`left_lean_neck` p02, `neck_light` p02, `slouch` p01에서는 기대 kind
검출률이 개선되지 않았다. 따라서 이번 보정은 정상 자세 오판을 줄이고
일부 자세의 검출을 개선했지만, 모든 자세와 참가자에 대해 일관된 성능
향상을 보장하지는 않았다.

**해석상 주의:** 정상 자세 데이터를 사용해 보정했으므로 정상 자세 판정률
향상은 보정 절차에 의해 구조적으로 유도될 수 있다. 핵심 검증은 정상
판정률 자체뿐 아니라, 보정에 사용하지 않은 이상 자세에서 기대 kind 검출
성능이 유지되거나 개선되는지에 있다.

## 6. 한계 및 후속 실험 제안

1.  현재 결과는 환경 2의 p01·p02 두 참가자 데이터에 한정된다. 다른
    참가자와 환경에서도 같은 효과가 나타나는지 확인해야 한다.
2.  참가자별 정상 데이터로 보정한 뒤 같은 참가자의 자세 로그를
    평가했으므로, 새로운 참가자에 대한 일반화 성능을 입증한 결과는
    아니다.
3.  `chin`과 같이 보정 후에도 검출률이 낮은 자세는 해당 자세에 적합한
    특징과 판정 조건을 별도로 점검할 필요가 있다.
4.  보정 전후 결과를 비교할 때 정상 판정률, 기대 kind 검출률을 구분해
    보고해야 한다. 두 지표를 전체 정확도와 동일하게 해석하면 안 된다.
5.  후속 평가에서는 참가자별·자세별 결과를 유지하고, 가능하면 독립된
    평가 데이터에서 검증한다.
